# Loveflix — Nossa História

Versão personalizada do Loveflix com textos inspirados na história do casal e nos momentos compartilhados.

## Executar
Abra `loveflix.html` no navegador.

## Personalizar
- Troque as imagens da pasta `assets/` pelas fotos reais.
- Adicione `assets/theme.mp3` para a trilha sonora.
- O texto da carta está no elemento `#letterText`.
- Os episódios podem ser alterados diretamente no HTML.

## Importante
Os textos foram personalizados com base nas informações e lembranças fornecidas durante as conversas. Eles podem ser ajustados para ficar mais íntimos, mais românticos ou mais fiéis a acontecimentos específicos.
